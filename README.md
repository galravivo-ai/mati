# סיכום פעילות שיווק – מט"י ירושלים

דשבורד חודשי של פעילות השיווק הדיגיטלי, מאת רביבו דיגיטל.

## מבנה התיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | העמוד עצמו – עיצוב, גרפים וטבלה. לא צריך לגעת בו. |
| `data.js` | **הנתונים** – זה הקובץ היחיד שמתעדכן כל חודש. |
| `assets/` | לוגואים וגופנים. |

## העלאה ל-GitHub Pages (פעם אחת)

1. יוצרים ריפו חדש ב-GitHub (למשל `mati-report`).
2. מעלים את כל התוכן של התיקייה (כולל `assets` ו-`.nojekyll`) דרך **Add file → Upload files**.
3. נכנסים ל-**Settings → Pages**, ובוחרים **Deploy from a branch** → `main` → `/ (root)` → **Save**.
4. אחרי דקה-שתיים העמוד זמין בכתובת `https://<שם-המשתמש>.github.io/mati-report/`.

### כתובת משלכם (אופציונלי)
ב-**Settings → Pages → Custom domain** מזינים למשל `report.revivodigital.co.il`,
ובניהול ה-DNS של הדומיין מוסיפים רשומת `CNAME` מ-`report` אל `<שם-המשתמש>.github.io`.

## עדכון חודשי

1. בריפו פותחים את `data.js` ולוחצים על העיפרון (Edit).
2. מחליפים את התוכן בגרסה החדשה (או מוסיפים שורות לחודש החדש).
3. **Commit changes** – תוך כדקה הדשבורד מתעדכן באותה כתובת.

### מבנה הנתונים ב-`data.js`
- `metrics` – שורה לכל חודש: `month` (בפורמט `2026-10`), `designs`, `newsletters`, `social_campaigns`, `organic_posts`, `special_projects`, `google_campaigns`.
- `activity` – שורה לכל משימה: `month`, `section` (תחום), `item` (תיאור), `qty` (כמות, או `null`).

הדשבורד נפתח תמיד על החודש האחרון שמופיע בנתונים.

> שימו לב: GitHub Pages ציבורי – כל מי שיש לו את הכתובת יכול לראות את הדשבורד. העמוד מסומן כך שמנועי חיפוש לא יציגו אותו.
